# Farm Production and Profitability Analysis | Power BI

## Project Overview

This project is an interactive agricultural analytics dashboard developed using Microsoft Power BI.

The dashboard explores farm production, financial performance, crop profitability, and regional agricultural output.

It combines key performance indicators with data visualisations to provide an overview of farm operations and financial results.

The project demonstrates how data analytics can be used to examine agricultural performance and support informed business decisions.

## Project Objectives

The main objectives of this project are to:

- Analyse total farm revenue, costs, and profit.
- Examine production output across different regions.
- Compare financial performance across different crops.
- Explore regional profitability.
- Present agricultural performance through interactive visualisations.
- Develop practical skills in data analysis and business intelligence.

## Dashboard Overview

### 1. Key Performance Indicators

The dashboard contains four KPI cards:

| KPI | Purpose |
|---|---|
| Total Profit | Displays the total profit measure |
| Total Farm Record | Shows the total farm record count |
| Total Cost | Displays the total cost measure |
| Total Revenue | Shows the total revenue measure |

These indicators provide a summary of agricultural and financial performance.

### 2. Total Production by Region

A line chart visualises total production in tonnes across different regions.

This helps explore differences in agricultural output between geographical areas.

### 3. Profit, Revenue and Cost by Crop

A clustered column chart compares total profit, revenue, and cost across different crops.

This visualisation allows users to examine the financial performance of individual crop categories.

### 4. Total Profit by Region

A clustered column chart presents total profit across different regions.

This helps compare regional profitability and identify areas for further financial analysis.

### 5. Additional Agricultural Performance Visualisation

The dashboard also includes a 100% stacked bar chart for exploring agricultural data across categories.

The chart provides a proportional comparison of the categories represented in the report.

## Business Questions

The dashboard is designed to explore the following questions:

1. What are the total revenue, cost, and profit recorded in the dataset?
2. How does agricultural production vary across regions?
3. How do profit, revenue, and cost compare across different crops?
4. Which regions contribute to the recorded farm profit?
5. How can agricultural performance be evaluated using financial and production metrics?
